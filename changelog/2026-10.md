# Changelog: October 2026

![Sarcomere Dynamics Inc. Logo](/docs/assets/images/common/logo.svg)

Sarcomere_Dynamics_Resources** repository has moved to **artusapi**.

All documentation included in this repository will focus on software development and implementation.
Hardware information can be found on the [Sarcomere Dynamics GitHub Quickstart Guide](https://github.com/Sarcomere-Dynamics/.github/blob/main/docs/hardware/quickstart.md)
Firmware releases will also be slowly migrated to [Sarcomere Dynamics GitHub Releases](https://github.com/Sarcomere-Dynamics/.github/releases), freeing this repository's Releases tab for API-specific releases.

Consequently, changes from the formerly labelled "ArtusAPI_V2" have been solidified in the newly labelled **artusapi**.

Several changes have been performed to ensure a smoother maintennance experience, especially related to issues concerning:

- PyPI release scheduling
- Product-specific documentation
- Provisioning firmware releases

## List of Updates

### Top-level

- Renamed ArtusAPI **package** to artusapi
- Renamed `ArtusAPI_V2` **class** to `ArtusAPI`
- Deprecated all references to "ArtusAPI V1"
- Deprecated `get_joint_angles()` and `set_joint_angles()` in favour of generalized `get_joint_feedback()` and `set_joint_targets()`

### Examples

- Deprecated "general example" and "GUI" in favour of **artusutil**
- Deprecated legacy ManusGloveControl example
- Deprecated StandardBotsDemo
